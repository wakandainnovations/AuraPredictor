# india_prev_movies_data_collection — web-verified budget / revenue / verdict

One run = 100 movies, worked in 20 batches of 5. Each batch is written to the DB
as soon as it is verified, so an interrupted run loses at most one batch.

## Files

| File | What it holds |
|---|---|
| `PROGRESS.md` | this file: rules, run log, next-run prompt |
| `runs/run_NNN_movies.json` | the 100 movies chosen for run N, with batch numbers and pre-run values |
| `runs/run_NNN_batch_BB.json` | findings for one batch, as applied (audit trail) |
| `processed.csv` | every movie already reviewed (found or not) — never picked again |
| `changes.csv` | every DB change: old value → new value, ₹ crore, rate, rate date, source URL |
| `missing_data.csv` | **movies where budget / revenue / verdict was not found — for manual follow-up** |
| `boi_index.csv` | Box Office India movie index (5,269 Hindi titles from its sitemap) — title, year, verdict, budget, grosses, page URL; built by `scripts/boi_index.py` |
| `deleted_pak_bd_rows.csv` | the 88 Pakistani / Bangladeshi rows (incl. 10 Bangladesh–India co-productions) deleted on 2026-11-14 at the user's request (also in table `india_prev_movies_data_collection_pak_bd_backup_20261114`); removed from `processed.csv` / `missing_data.csv`, kept in `changes.csv` |
| `deleted_pre2005_rows.csv` | the 850 pre-2005 rows deleted on 2026-11-01 (also in table `india_prev_movies_data_collection_pre2005_backup_20261101`) |

Script: `scripts/prev_movies_bo_review.py` (`next`, `apply`, `status`). BOI index: `scripts/boi_index.py` (crawl / `find <title>`).
Rechecking gap movies from an earlier run (e.g. against a new source): `apply <file> --run N --batch B --recheck`.
Add `--override` to let budget / revenue replace an already-stored value (used only to store the average of conflicting figures; notes tagged `recheck override`). Without it, a recheck it only accepts fields listed as gaps in `missing_data.csv`, removes filled gaps from that file, updates the movie's
statuses in `processed.csv` (no new row), and tags the `changes.csv` rows with `recheck`. Name the files `runs/run_NNN_recheck_BB.json`.

## Rules (every run)

- **Order:** `times_needed DESC, release_date DESC, tmdb_movie_id` — the most-used prev films first. Key is `tmdb_movie_id` (unique; `id` is NULL on many rows).
- **Not found → leave the DB value as is**, and the movie goes into `missing_data.csv`.
- **Only figures read from a source page.** No estimates, no memory. Every number carries a source URL.
- **Budget:** production budget. Ranges ("₹40–50 crore") → midpoint, noted.
- **Revenue:** worldwide gross preferred; if only India gross/net exists use it and set `revenue_scope`.
- **Source priority for budget / revenue: Wikipedia first, then Box Office India (BOI), then the rest** (BH year table, sacnilk, Koimoi, news). Use a BOI figure only when Wikipedia has no usable figure for that field (blank, uncited, `{{citation needed}}`, a distributors' share, or a partial running total). When a cited Wikipedia figure and BOI disagree, keep Wikipedia and note the BOI value. Check BOI for **every** movie (see "Box Office India" below); a BOI verdict counts like any other source, so a BOI-vs-Wiki/BH verdict conflict → NULL.
- **Conflicting budget / revenue figures → store the average** (user rule, 2026-11-14 — replaces "keep Wikipedia" / "leave NULL" for figures): this applies to stored values too (a cited Wikipedia figure no longer wins over a differing BOI / BH / sacnilk figure — average them; differences ≤ 3% count as agreement, and a figure that is a subset of the other, e.g. India-only vs worldwide containing it, is not a conflict); when sources disagree on a budget or revenue figure, store the mean of the conflicting figures (a range counts as its midpoint) and list every figure + source in `notes`; set `revenue_scope: unknown` when the averaged figures mix nett / gross / worldwide. An approximate number is better than none. Not a conflict: BOI pages whose `Total Nett Gross` merely repeats the inflation-`Adjusted Nett Gross` (use India gross). Verdict conflicts still → NULL.
- **Currency:** INR figures entered in crore; the script converts at the `currency_rate_xe` INR→USD rate nearest the release date (≤120 days away; the corrupt 3.75 rows are ignored). Figures given only in USD are entered as USD.
- **hit_flop_avg** (new text column) from a source's stated verdict or clear verdict wording:
  - `hit`: Semi-Hit, Hit, Super Hit, Blockbuster, All-Time Blockbuster, "commercial success"
  - `avg`: Average, Above Average, "break-even" / "moderate success"
  - `flop`: Below Average, Flop, Disaster, "box-office bomb", "commercial failure"
  - nothing stated → left NULL and listed as missing. A verdict is never guessed from the numbers.
- Changed values get `budget_source` / `revenue_source` = `websearch:<domain>`.

## Lessons from earlier runs (read before searching)

- **Existing Wikipedia-sourced values were converted correctly** — re-deriving them reproduced the stored USD to the dollar. The value of a run is mostly filling gaps, setting verdicts, and catching non-gross figures.
- **Bollywood Hungama year tables** give a verdict + India lifetime nett for nearly every Hindi release:
  `https://www.bollywoodhungama.com/box-office-collections/filterbycountry/IND/<YEAR>/` — fetch once per year and ask only for the titles you need.
- Per movie, fetch `https://en.wikipedia.org/wiki/<Title>` (try `_(<year>_film)` / `_(film)` on 404) and ask for the infobox Budget / Box office verbatim plus any verdict sentence.
- **Also check Box Office India** for every movie — see the "Box Office India" section below. Wikipedia figures are preferred; BOI fills what Wikipedia lacks.
- **Watch for "distributors' share"** in infoboxes (common for Telugu/Tamil) — it is not gross; don't store it as revenue.
- Conflicting verdicts between sources (e.g. Wikipedia "commercial success" vs BH "Flop") → leave NULL, note the conflict.
- "Underperformed" / "poor opening" alone is not a verdict → NULL.
- Direct-to-streaming films (Netflix/Prime) have no box office → leave as is, note it.
- **Koimoi "Plus"** verdict = profitable but below Hit → mapped to `avg` (Nikka Zaildar 4).
- **Ranges in Wikipedia infoboxes** (budget or gross) are already stored as midpoints — re-deriving the midpoint reproduces them.
- **"Highest-grossing <language> film" / "biggest opening"** are rankings, not verdicts → NULL.
- **Wikipedia vs BH verdict conflicts are common for 2005–2015 Hindi films** (BH tends to be harsher); run 2 had 7 such conflicts.
- Partial running totals ("₹50 Cr in two weeks", opening weekend) are not lifetime gross → don't store.
- **Stored Telugu revenues are often distributors' shares** (run 3: 100% Love, Don Seenu, Chirutha, Agnyaathavaasi). `apply` can't null a value, so a share with no gross to replace it stays flagged in notes.
- **BH year tables omit many small Hindi releases** (shorts, direct-to-video, 2005–2008 small films); don't spend more searches on them.
- **sacnilk movie pages** (`https://www.sacnilk.com/movie/<Title>_<year>`) give budget, WW gross and a verdict (Hit / Blockbuster …) for many 2019+ regional films; their header totals often disagree with their own day-wise table, and the 'figures till' date shows whether the run was complete (run 4).
- **Disambiguation pages are common** for regional titles: retry `<Title>_(<year>_film)`, `_(film)`, `_(<year>_<language>_film)`.
- Regional films without Wikipedia figures are rarely findable; one targeted search (sacnilk / koimoi) is enough before marking missing.
- **sacnilk's "Worldwide gross" header is often wrong for small films** (lower than its own India gross, run 5). When overseas is "—"/0, store the India gross line as `india_gross`. If 'figures till' is the release day or the end of week 1, it is a partial total → don't store.
- **BH 2005–2009 year tables list only the bigger releases**; most small Hindi films from those years have no BH entry (run 5).
- **sacnilk shows a default "Disaster" verdict on pages with ₹0.00 data** (e.g. Pranaya Vilasam, a Wiki "super hit"). Use a sacnilk verdict only when the page has real figures (run 6).
- **Box Office India was down from run 6 to run 22** (maintenance page / HTTP 500); it is **back up as of 2026-11-07**. The run-log notes "Box Office India not tried" for runs 6–22 are history, not instructions — check BOI on every run. If it is down again, note it in the run log and continue with Wiki / BH / sacnilk.
- **Wiki infobox ranges are sometimes stored at the range top** instead of the midpoint (run 6: Yashoda, Major). Re-derive the midpoint and correct it.
- **Fetching Wikipedia in parallel trips HTTP 429** (run 7). Query the API one request at a time with a short sleep and back off on 429.
- **filmibeat's 'highest grossing Tamil movies of <year>' list** (e.g. the 2015 one) gives lifetime figures for the year's top 20 Tamil films; scope is usually not stated → `unknown`. Sakshi's 'Hit Kannada Films in <year>' list is a usable verdict source for Kannada films (run 7).
- **BH movie pages** (`/movie/<slug>/box-office/`) for 2006–2008 films mostly say 'No Data Found'; a slug can belong to an older namesake (run 8: `victoria-no-203` is the 1972 film — check `datePublished`). Wiki mirrors (bharatpedia, wikimili) sometimes carry figures removed from the current article as unsourced — don't use them. A redirect to a franchise's first film (My Friend Ganesha 2 → My Friend Ganesha) is not the sequel's data (run 8).
- **sacnilk's page layout changed by run 9**: most pages show only a 'Box office so far' block (Worldwide gross · N days, Figures till, India net / gross, Overseas) with no budget and no verdict; a `Verdict` and `Budget:` appear on some pages. Its 'Worldwide gross' header is still often below India gross — use the India gross line then. Pages with only 1–7 days are partial (don't store). Pages for direct-to-OTT or untracked films show '—' everywhere plus a default 'Disaster' (ignore).
- **Wiki gross cited to a day-N / 'crosses ₹X crore' article** is a running total (run 9: Ajey, Kingston, Kaapa, Nanpakal Nerathu Mayakkam). Replace it with a sacnilk end-of-run total if there is one, else flag it.
- **sacnilk slugs often carry a working title or the announcement year** (run 10: `Naane_Varuven_2021`, `Suriya_40_2021` = Etharkkum Thunindhavan, `Bheeshma_Parvam_2021`, `Bangaraju_2022`). On a 404, search `sacnilk <Title> box office` and fetch the `/movie/` URL it returns. Fetch sacnilk with WebFetch; curl with a spoofed browser user-agent is blocked by the permission classifier.
- **A Wiki infobox gross can be an opening-day figure** (run 10: PM Narendra Modi ₹2.51 Cr vs BH lifetime ₹23.70 Cr) — cross-check Hindi films against the BH year table. A Wiki range built from two disagreeing sources (Etharkkum Thunindhavan '₹71.4–200 Cr') is not a real range; use the figure a second source confirms.
- **2020–2021 lists are full of COVID-era direct-to-OTT films** (run 10: 26 of 100). The Wiki lead usually says 'premiered on <platform>' — mark those without further searching.
- **Re-released cult films carry two grosses in the infobox** ('₹15.46 crore (initial run) / ₹38 crore (re-release)'). Store the initial run — the stored value was the re-release figure for Tumbbad and Sanam Teri Kasam (run 11). Also check the cite date of an infobox gross: a BOI/news article dated days after release is a running total (Ambarsariya, run 11).
- **The bulk Wiki search can pick the wrong article** (run 11: Rabb Da Radio 2 → the 2017 prequel, Pyaar Actually → Yeh Raaste Hain Pyaar Ke, Dandupalya 3 → Dandupalya, The Hero (2016) → the 2003 film). Check the matched title/year before using its figures.
- **2012–2015 regional films are mostly verdict-only on Wikipedia** (run 12: 32 verdicts but only 13 new figures from 100 films); general web searches for them return only pre-release predictions — one search at most, then mark missing. A review's 'disaster' (Rediff on Alex Pandian) is about quality, not box office. A Wiki lead linking 'disappointed at the box office' to *Box-office bomb* was taken as `flop` (Double Barrel).
- **2007–2011 South films: the stored Wiki revenue is very often a distributors' share** (run 13: 6 of 100 — Telugu above all). Inline wording like 'a hit'/'blockbuster' in the Wiki lead is the main yield for these years; figures beyond the infobox are rare. 'Musical hit' (soundtrack) and 'average reviews' are not box-office verdicts.
- **The Wikipedia API can return HTTP 429 for scripted curl/urllib requests** (run 14: every request, from the start). Don't retry with other user-agents; read Wiki pages with WebFetch instead (5 in parallel worked fine).
- **2025–2026 Wiki infobox grosses cited to a TOI 'box office hits that turned big profits' listicle ('est. ₹110 crore')** run well above sacnilk/Koimoi end-of-run totals (run 14: Thalaivan Thalaivii, Madha Gaja Raja) — flag them rather than confirm.
- **2023–2024 small regional films: sacnilk pages are the main yield, but many 2023 pages show only '—' ('No box office figures yet')** and many others stop at day 7 (run 15). Wiki infobox grosses cited to TOI '<film> box office collections: … mints Rs X crore' articles dated days after release are running totals (Mission: Chapter 1, Dhoomam) — check the cite date. Hindi 2023–2024 small films: BH year table gives lifetime + verdict in one fetch.
- **2022 Malayalam/Telugu Wiki infobox grosses are often producer 'crore club' claims or day-N totals** well above sacnilk's end-of-run WW (run 16: Malikappuram ₹99 vs 52.4, Paappan ₹50 vs 28.2, 18 Pages ₹25 vs 23). Check the cite title/date and the sacnilk 'Figures till' date; correct when sacnilk covers the full run (≈3+ weeks), flag when it stops at ~2 weeks. **T2Blive 'Total Collections' cites** (Telugu) may be shares — don't confirm them blind. A Wiki infobox with identical budget and box office from one cite (Sherdil) is suspect.
- **2019–2021 lists: ~20% are COVID-era direct-to-OTT / TV premieres, and 2019 Kannada/Tamil/Telugu Wiki infoboxes are almost all blank** (run 17). ## Box Office India (BOI)

Back up as of 2026-11-07 (checked: plain curl → HTTP 200). Use it for every movie, **after** Wikipedia.

**Local index — use this first.** `boi_index.csv` (this folder) holds every movie page in BOI's sitemap: 5,269 movies (ids 1–6927), one row each with title, year, language, verdict, release date, budget, first day / weekend, total nett, India / overseas / worldwide gross and the page URL. Built 2026-11-07 by `scripts/boi_index.py`.
- Look a title up: `venv/bin/python scripts/boi_index.py find <title>` (substring match, punctuation ignored), or load the CSV and match on normalised title ± 1 year.
- **The sitemap is Hindi-only** (5,078 Hindi rows + Hindi dubs of South films, a few Tamil/Telugu/English). Regional films are not in it, so BOI won't fill regional gaps — don't search further for them.
- Re-running `scripts/boi_index.py` resumes / adds new sitemap ids (2 s pause, one request at a time — agreed with the user; robots.txt allows `/movie`). Run it under `caffeinate -i` on AC power: on battery the Mac drops into Maintenance Sleep and the crawl silently stalls (run 22: two ~18-min stalls). It stops on a Cloudflare challenge — don't work around one.
- Its parsed figures are fine for matching; **cite and spot-check the live page** (`movie.php?movieid=<id>`) for anything you store.

**Not in the index?** Movie pages are `https://boxofficeindia.com/movie.php?movieid=<id>`. A Wikipedia raw-wikitext cite to `boxofficeindia.com/movie.php?movieid=` gives the id; otherwise one web search (`boxofficeindia <Title> <year>` — search engines index BOI poorly). Don't use BOI's own search: `search?search=` renders without results for curl, and the `getSearch.php` autocomplete is behind a Cloudflare bot check.

**Check the match**: title, year and language line ("Toss (2009) Hindi"), and the director/cast on the page when the year differs. BOI records the **India release**, which can be years after a festival premiere (run 22: Life Goes On 2009 fest → BOI 2011; Before the Rains 2007 TIFF → BOI 2009). Same-named films are common (run 22 false hits: Happy Husbands = the 2011 Hindi remake, not the 2010 Malayalam film; Blue ≠ Blue Oranges; Dharm ≠ Dharmapuri).

**Reading the page** (plain curl works; strip tags). Fields, in INR rupees written with Indian digit grouping (`3,00,00,000` = ₹3 Cr):
- `Budget:` → `budget_inr_crore`
- `Worldwide Gross :` → revenue with `revenue_scope: worldwide` when `Overseas Gross` has a figure. When overseas is `$---`, Worldwide just repeats `India Gross` → store that figure with `india_gross`.
- `Total Nett Gross :` → `india_net`, only when the page has no gross line at all.
- Ignore `Adjusted Nett Gross` (inflation-adjusted), `First Day`, `First Weekend` and `Footfalls`.
- The verdict label at the top of the page (Disaster / Flop / Below Average / Average / Above Average / Semi Hit / Hit / Super Hit / Blockbuster / All Time Blockbuster) → map with the `hit_flop_avg` rules. `User Verdict` is a reader poll — ignore it.

**Priority.** Wikipedia first: use BOI for a field only when Wikipedia has no usable figure for it (blank, uncited, `{{citation needed}}`, distributors' share, partial running total). When a cited Wikipedia figure disagrees with BOI by more than ~3%, keep Wikipedia and note the BOI value. Cite the BOI movie URL in `sources`; `budget_source` / `revenue_source` becomes `websearch:boxofficeindia.com`.

Example (applied in run_022_recheck_01): Toss (`movieid=1097`) — Budget 3,00,00,000 (₹3 Cr), Worldwide Gross 19,50,000 (₹0.195 Cr — matches the stored Wiki ₹19 lakh, which is itself cited to BOI), verdict **Disaster** → `flop`.

**What BOI yields for small Hindi films:** nearly all are 'Disaster' with a budget and a tiny India gross (run 22: 16 of 19 Hindi gap films matched, all Disaster). Where a cited Wiki gross disagrees, Wiki is kept and the BOI value noted (Return of Hanuman: Wiki ₹6.14 Cr via BOM vs BOI ₹2.56 Cr India gross).
